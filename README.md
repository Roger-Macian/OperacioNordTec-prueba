***Llista de passos per pujar un canvi a GitHub***

* Editar els fitxers
* Guardar els canvis
* Fer `git status`
* Després fer un `git add fitxer` o `git add .`
* Seguidament del `git add` fem un commit amb `git commit -m "Canvis fets respecte al últim commit"`
* I per finalitzar, fem un `git push -u origin main`

#### Repositori de GitHub
[https://github.com/Roger-Macian/OperacioNordTec.git](https://)

#### Bloc de comandes
```
git init
git status
git add arxiu / Git add .
git commit -m "Canvis fets respecte al últim commit"
git branch
git remote add origin <url-del-repositorio>
git push -u origin main
git pull
```

### Taula de comandes + explicació


| Comandes | Expliacació
| -------- | -------- | 
|`git init`| Inicia git|
|`git status`|Comprova el estat dels arxius del projecte|
|`git add arxiu o Git add .`| Afageix els arxius editats al git|
|`git commit -m "Canvis fets respecte al últim commit"`| Fa un commit amb els arxius editats, aixi el projecta queda junt|
|`git branch`| Serveix per veure la branca en la que estas|
