***Llista de passos per pujar un canvi a GitHub***

* Editar els fitxers
* Guardar els canvis
* Fer `git status`
* Despres fer un `git add fitxer` o `git add .`
* Seguidament del `git add` fem un commit amb `git commit -m "Canvis fets respecte  al ultim comit"`
* Y per finalitzar, fem un `git push -u origin main`
